OpenCloudreve 移动客户端的第一个版本，支持 Android 与 iOS / iPadOS，对接 [OpenCloudreve](https://github.com/Lynricsy/OpenCloudreve) 服务端（Cloudreve v4 社区版分支）。

## 功能

- **登录与账户**：密码、两步验证、Passkey、注册与找回密码，支持各类验证码；多站点多账户切换；需要网页完成的操作会带着当前登录状态打开网页。
- **文件浏览**：列表 / 网格视图、排序、多选、移动 / 复制 / 重命名 / 删除、回收站、搜索、固定位置、文件信息与版本、元数据与标签；目录排序和视图设置与网页端同步；目录内容变化实时刷新。
- **传输**：后台上传与下载，支持暂停、续传、取消；兼容本机、从机、S3 / OSS / COS / OneDrive 等存储策略；可从系统分享菜单把文件上传到云端。
- **预览与编辑**：图片（含 EXIF）、视频（含字幕）、音乐（后台播放、锁屏控制）、PDF、Markdown、文本编辑、压缩包浏览与解压，以及站点配置的网页预览器。
- **分享与任务**：创建与管理分享链接（密码、有效期、下载次数），打开他人分享并保存；压缩 / 解压、离线下载等后台任务。
- **设置与个人中心**：头像、昵称、语言、主题色、安全设置、WebDAV 账号、已授权应用。
- **轻量管理**：管理员可查看概况、用户、分享、任务、节点等。
- **系统集成**：Android 系统「文件」应用中可直接浏览云端（DocumentsProvider）；iOS「文件」App 集成（File Provider）；支持 `cloudreve://` 与 `opencloudreve://` 链接。
- 简体中文与英文界面，深色模式，平板与大屏布局。
