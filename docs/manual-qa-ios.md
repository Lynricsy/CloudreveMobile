# iOS 真机验证清单

模拟器与 CI 无法覆盖的行为（后台 URLSession 存活、Share Extension、File Provider）在这里列出，需在真机上逐项验证。
真机构建需要开发者团队签名：App、`plus.ling.opencloudreve.share`、`plus.ling.opencloudreve.fileprovider` 三个 target 都要开启 App Group `group.plus.ling.opencloudreve` 与 Keychain 共享组 `plus.ling.opencloudreve.shared`。

## File Provider（系统“文件”集成）

前置：服务端可访问；准备两个账户（A、B，可在不同站点），A 的“我的文件”里有若干目录（其中一个超过 200 项）、一张图片、一个 PDF。

1. **域的增删**
   - 登录 A → 打开“文件”App →“位置”中出现 `<A 昵称> @ <host>`（若未出现：“浏览”页右上 `…` → 编辑，打开 OpenCloudreve）。
   - 再添加账户 B → 出现第二个位置 `<B 昵称> @ <host>`。
   - 在 App 内登出 B → B 的位置消失；A 仍在。
2. **浏览与分页**
   - 进入 A 的根目录：条目、大小、修改时间与 App 内一致；目录可进入。
   - 进入超过 200 项的目录并滚动到底：全部条目都加载出来（游标分页 / 页码分页均可）。
   - 断网后再进入已浏览过的目录：显示系统缓存的条目；进入从未浏览过的目录：提示无法连接服务器。
3. **打开内容**
   - 点按图片、PDF：下载后用系统预览打开；再次打开不重复下载。
   - 打开“分享到我的文件”的软链接文件：内容来自链接目标。
4. **创建**
   - 新建文件夹 → App 内同一目录出现该文件夹。
   - 从“照片”或其它位置拷贝一个文件（≥ 50 MB）到 A 的目录 → 上传完成后 App 内可见，大小一致；Web 端可预览。
   - 再拷贝同名文件 → 系统自动改名（如 `a 2.jpg`）后上传，不覆盖原文件。
5. **修改**
   - 重命名文件、目录 → App/Web 端名称同步。
   - 在 A 内把文件拖到另一个目录 → 服务端移动成功。
   - 用支持就地编辑的 App（如 Pages/文本编辑器）修改一个 txt 并保存 → 服务端生成新版本（App 内“版本”可见），文件 id 不变。
6. **删除**
   - 删除文件 → 进入 Cloudreve 回收站（App 内“回收站”可见，可还原），不是彻底删除。
7. **主 App 联动**
   - 保持“文件”App 打开 A 的某目录，在 OpenCloudreve App 内对该目录新建文件夹 / 重命名 / 删除 → 切回“文件”App，几秒内列表刷新。
8. **登录失效**
   - 在 Web 端修改 A 的密码（使 refresh token 失效）→ 在“文件”App 中刷新 A：提示需要登录（notAuthenticated）；回 App 重新登录后恢复。
9. **权限位**
   - 浏览“与我共享”之外不可写的位置（如管理员禁止上传的用户组）：系统不提供新建/拷入/重命名操作。

已知限制：
- 服务端没有增量变更流，系统每次收到刷新信号都会重新完整枚举工作集（最近浏览过的 50 个目录）。
- 上传、下载在扩展进程内同步完成（整片读入内存，内存占用约为“分片大小 × 并发数”）；大文件期间切走“文件”App 可能被系统挂起，回来后由系统重试。
- 扩展创建的传输任务完成后即从传输列表删除，主 App 的传输页不显示这些任务。

## 后台传输与分享扩展（IOSTransfer）

前置：真机已登录账户 A（本机存储策略，分片 25 MB）；准备一个 ≥ 300 MB 的视频（相册）与一个 ≥ 100 MB 的文件（“文件”App 中，例如 iCloud Drive）。
传输由后台 `URLSession`（主 App `plus.ling.opencloudreve.transfer`，分享扩展 `plus.ling.opencloudreve.transfer.share`）执行，任务状态在 App Group 数据库中。

1. **前台上传与迷你栏**
   - 文件 Tab → 某目录 → 右上“新建” →“上传照片或视频”→ 选择 300 MB 视频 →“开始上传”。
   - 预期：Tab 栏上方出现“上传 1 项 xx%”迷你栏；点按进入“任务”Tab，看到进度条、速度、剩余时间；完成后行显示“已完成 · 大小”，目录刷新后可见该文件，Web 端可播放。
   - Live Photo：选择一张实况照片 → 只上传照片本体（HEIC/JPEG），不出现配对的 MOV。
2. **后台存活**
   - 开始上传 300 MB 视频后立即回到主屏幕并锁屏 3 分钟。
   - 预期：解锁打开 App，任务已完成或进度明显推进（分片在后台继续发送；系统可能在 App 被唤醒处理完成事件时补发下一片）。
3. **进程被杀后续传**
   - 上传进行到约 30% 时，在多任务界面上划结束 App（强制退出会让系统取消后台任务）。
   - 重新打开 App：任务从已确认的分片继续（进度不归零，`local/remote/s3/oss/onedrive/qiniu/ks3` 复用原会话），最终完成；服务端只有一个完整文件。
   - 下载同理：下载一个 ≥ 200 MB 文件到一半时强制退出 → 重新打开后从 resumeData 继续（或从头重新下载），完成后文件大小正确。
4. **暂停 / 继续 / 取消 / 冲突**
   - 上传中点“暂停”→ 状态“已暂停”且服务端不再增长；点“继续”→ 从断点继续。
   - 下载中暂停后继续：不从 0 开始（resumeData）。
   - 上传中左滑“取消”→ 状态“已取消”，Web 端没有残留的占位文件；“清除已完成”移除已完成/已取消项。
   - 上传一个目录中已存在的同名文件 → 失败“目标位置已有同名文件”；长按 →“重命名后上传”输入新名成功；或“覆盖为新版本”后该文件版本数 +1。
5. **下载位置与导出**
   - 多选 3 个文件 → 底栏“下载”。预期：迷你栏“下载 3 项”；完成后“文件”App →“我的 iPhone › OpenCloudreve › Downloads › <昵称>”中可见；同名文件自动命名为 `名称 (1).ext`。
   - 已完成的下载行右侧“导出”按钮打开系统分享面板，可存储到“文件”或用其它 App 打开。
6. **文件选择器上传（书签）**
   - “上传文件”选择 iCloud Drive 中 100 MB 文件 → 上传过程中切到后台 → 完成（源文件通过安全作用域书签读取，不复制）。
   - 上传前在“文件”App 中删除该源文件 → 任务失败“无法读取本地文件”。
7. **拍照上传**
   - 新建菜单 →“拍照上传”→ 拍一张 →“开始上传”→ 目录中出现 `IMG_yyyyMMdd_HHmmss.jpg`。
8. **分享扩展实际上传**
   - 在“照片”中选 5 张照片 + 1 段视频 → 分享 →“上传到 OpenCloudreve”。
   - 预期：扩展列出 6 个文件；多账户时可切换账户（目标目录回到“我的文件”）；“上传到”可选目录、可新建文件夹；存储策略限制（大小/扩展名）不满足的文件显示红色提示。
   - 点“上传”→“已开始上传 6 个文件”→“完成”关闭扩展。不打开主 App 等待几分钟（系统在扩展退出后唤醒主 App 继续后续分片），再打开 App：任务 Tab 中 6 项均为已完成，目标目录可见。
   - 未登录任何账户时分享 → 提示“尚未登录”。
9. **分享扩展：分享链接**
   - 在 Safari 打开 `https://<站点>/s/<id>` → 分享 →“上传到 OpenCloudreve”→ 显示“这是一个 OpenCloudreve 分享链接”→“在 App 中打开”。
   - 预期：宿主允许时直接打开 App 并弹出分享浏览；不允许时显示“已复制链接…”，打开 App →“打开分享链接”粘贴可浏览。
   - 在“备忘录”中分享一段普通文字 → 作为 `.txt` 文件上传。
10. **收件箱清理**
    - 上传完成或取消后，App Group `Inbox/` 中对应副本被删除（Xcode → Devices → 下载 App 容器检查；`Inbox/` 不应持续增长）。

已知限制：
- 准备上传会话（`PUT /file/upload`）与收尾/回调请求由共享层的 Ktor 在 App 进程内发出，不在后台会话中；若这一步发生时 App 已被挂起，会在下次唤醒或打开 App 时（`reattach`）继续。
- 分享扩展只发出第一批分片后即关闭；后续分片依赖系统在后台事件完成时唤醒主 App。若主 App 已被用户强制退出，系统不会唤醒，需手动打开 App 继续。
- 网络错误按 1s/2s/4s 退避重试 3 次后标记失败，需在任务列表中手动“重试”。

## 预览与编辑（IOSViewers）

CI 的 `ViewerUITests` 已覆盖：打开方式选择、图片 + EXIF 面板、视频外挂字幕、音乐播放页与底部“正在播放”、PDF、Markdown 预览/编辑/保存、压缩包目录树（素材见 `scripts/ci/seed-viewer-media.py`）。以下需要真机或完整前端的服务端：

1. **实况照片**：用 iPhone 拍一张实况照片，经 App 上传（带 `customize:live_photo`）→ 打开 → 底栏“实况”→ 自动播放一次，长按可再次播放。
2. **后台播放与锁屏控制**：打开一个有多首歌曲的目录中的任一首 → 关闭预览、锁屏 → 锁屏/控制中心显示标题、作者、封面（站点能生成缩略图时）与进度；播放/暂停、上一首/下一首、拖动进度都生效；一首结束后自动播放下一首。主界面底部附件栏显示“正在播放”，点按打开播放面板，“×”停止并清除锁屏信息。有进行中的传输时附件栏优先显示传输进度。
3. **签名地址刷新**：把站点存储策略的签名有效期调短（如 2 分钟），播放长视频超过有效期 → 不中断、不跳回开头。
4. **HLS**：打开 `.m3u8` 视频可播放。
5. **保存冲突**：在网页端修改同一 Markdown 并保存 → 回到 App 内编辑后保存 → 出现“文件已在其他地方被修改”，“覆盖”后网页端刷新可见 App 的内容；“另存为…”在同一目录生成新文件。用 WebDAV 客户端锁定该文件后保存 → “文件已被锁定”→“强制解锁并保存”成功。超过站点“在线编辑大小上限”的文本保存时提示文件过大。有未保存的更改时点“关闭”→ 确认对话框。
6. **解压**：压缩包预览中勾选部分条目 → “解压到…”→“解压所选”→ 选择目标文件夹 → “开始解压”→ 任务完成后目标目录只含所选条目；GBK 编码的 zip 选“文件名编码 → gbk”后中文名正常。
7. **网页预览器**（需要构建了前端的服务端 ≥ 4.19.11）：打开 `.drawio` → 应用内网页免登录进入 draw.io 编辑器，保存后网页端可见；custom 预览器设置 `openInNew` 时用 Safari 视图打开；`nplayer://` 等非网页地址交给对应 App。服务端 < 4.19.11 时显示“需要更新服务端”。
8. **无可用预览器**：打开 `.docx`/`.key` → 下载进度后用快速查看显示；不支持的格式显示“分享”按钮。
